# Given Prince MABHENA — IT Professional Portfolio

A modern, responsive single-page portfolio built with **vanilla HTML, CSS, and JavaScript**. It showcases my certifications, technical skills, and live production projects across Python, cyber security, Cisco networking, and full-stack web development.

🔗 **Live site:** [thaizycelby.github.io/My-Profile](https://thaizycelby.github.io/My-Profile/)

---

## ✨ Features

- **Single-page app with hash routing** — Profile, Skills, Certificates, Portfolio, and Contact sections load instantly without a page refresh.
- **Animated UI** — [AOS](https://michalsnik.github.io/aos/) scroll animations, animated counters, and skill progress bars.
- **Responsive design** — Mobile-first layout with a collapsible hamburger menu, tested across desktop, tablet, and phone widths.
- **Accessible contact form** — Real-time validation with clear error states; send your message directly via **WhatsApp** or **Email** with one click.
- **Live project cards** — Every project links to its hosted demo and GitHub repository.
- **Dark theme** — Modern dark palette with subtle glowing orbs and glass-morphism navbar.
- **Zero build tools** — Pure static files; deploy to GitHub Pages, Netlify, Vercel, or any static host.

## 🛠️ Tech Stack

- **HTML5** — semantic markup, SEO meta tags, Open Graph tags
- **CSS3** — custom properties (variables), Grid, Flexbox, animations
- **JavaScript (ES6+)** — vanilla, modular IIFE pattern, no frameworks
- **Backend (Projects 1, 4)** — Python 3, Django, PostgreSQL / SQLite, WSGI
- **Libraries (CDN):**

  - [Google Fonts – Inter](https://fonts.google.com/specimen/Inter) — typography
  - [AOS 2.3.4](https://michalsnik.github.io/aos/) — scroll animations
